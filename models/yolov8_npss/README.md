# Optional plant-disease ONNX weights (gitignored binaries)

This folder holds **local-only** vision artifacts. Do **not** push `.pt` / `.onnx`
to GitHub (hundreds of MB).

## Expected layout

```text
models/yolov8_npss/
  PlantDiseaseDetection.pt   # source Ultralytics weights (optional once ONNX exists)
  best.onnx                  # required for VISION_BACKEND=auto|onnx
  labels.yaml                # class names (generated by setup script; tracked)
```

## One-command setup

From the repo root:

```powershell
pip install ultralytics onnx onnxruntime pyyaml
python scripts/setup_vision.py --pt models/yolov8_npss/PlantDiseaseDetection.pt
```

Then in `.env`:

```env
VISION_BACKEND=auto
```

Restart the API / rebuild the Docker `api` service. Without `best.onnx` the app
falls back to pixel vegetation CV automatically.

## Source model

Ultralytics YOLO11 object-detection weights (`PlantDiseaseDetection.pt`) with
116 plant disease / leaf classes. Export uses opset 17 → `best.onnx`
(~218 MB). See [Docs/VISION_PIPELINE.md](../../Docs/VISION_PIPELINE.md).
